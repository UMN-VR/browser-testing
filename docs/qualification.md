# Campus browser qualification

Status: source prepared; every new assertion, fixture, declaration and browser
run is **UNRUN**. The primary holds a bounded CPU grant for the sealed assertion
fixtures and syntax checks; this child performs source preparation only. Source preparation does
not qualify an application, renderer, worker, media release or remote setting.

This repository owns application routes, retained-content expectations and
assertions. It uses the public shared helper and copies no generic browser
runner, lifecycle, transport, screenshot or evidence implementation. The caller
supplies an explicitly checked compiled club assembly, named local fixture
origin, disposable profile, installed browser/tool paths and fresh grant. The
caller owns its fixture servers and output directories. Importing these modules
starts no browser/server and acquires no tools.

## Owned assertions and fixture contract

The package entry is [routes.mjs](../src/routes.mjs), with the public structural
contract in [routes.d.mts](../src/routes.d.mts).
[createCompiledCampusFixture](../src/fixtures.mjs) consumes data; it launches,
verifies, installs and serves nothing. Archive/file-map seals and qualification
receipts must be checked by the appropriate public owner tools and frozen by the
grant caller before this fixture is accepted. Passing synthetically shaped
input to the unit assertions is not artifact qualification.

Required inputs include all four canonical paths, exact compiled HTML/release
and document seals, actual assembly/full-file-map verification, qualified App
native-host/worker and new Scenes composition receipts, compiled observation
source SHA256, the shared sheet pin and installed helper pin. The old Scenes
`d58408d` single-document release cannot qualify independent-child composition.
Every actual content document must first pass the public Scenes/image validators;
Campus's assertions compare retained authored facts, not format validity.

The controlled newer-version fixture also needs its measured HTML SHA256,
verification receipt and distinct actual build stamp. The runner binds the
loaded/published stamps and fetches its served HTML after explicit Reload;
an invented newer-version string cannot stand in for that compiled evidence.

The caller's compiled observation ports must read/exercise the real compiled
App: actual backend, one runtime/viewer/scheduler/broker/uploader, all thirteen
tab definitions and real tab text/labels/focus behavior, resolved cross-campus
navigation, report-only startup and worker/update behavior. Missing native,
composition, observation, keyboard or update ports are blockers. They are not
replaced with handwritten success snapshots or a website wrapper.

[Legacy expectations](../src/legacy-expectations.json) contain public authored
IDs, links, preview-cell identities and record digests. They retain no panorama
files or private importer input and are not runtime content. The source is the
unchanged legacy document: SHA256
`61c25d55523be24e4d937e594169c3d5d385f816005bc20bf209201c794686ed`,
377117 bytes, scene `umn-twin-cities`, revision `4b89d4e2af09`.

[Marker-style baseline](../src/marker-style-baseline.json) was measured from only
that exact authored JSON at the recorded archive path. It binds the same source
identity, revision, hash and byte count; all sixty original markers have no
individual style. The original root gives a `#ffcc33` outline of 2 CSS pixels and
a hover scale of 1.3. The public Scenes composition contract may materialize
that inherited appearance onto `marker.style`. Assertions first compare the
effective root/individual outline and hover to this measured baseline, then
remove only a verified equivalent materialized `marker.style` from the original
record hash. Geometry, captions, provenance, unknown height/north and aliases
stay in that unchanged hash. A compiled document must supply its actual root
style or materialized per-marker style; a missing root cannot silently use the
baseline. Optional resolved `markerStyle` observations must also match the
measured sRGB channels and hover scale. No generic style validator is copied.

The assertions cover Minneapolis48, Saint Paul12 and combined60; all134
combined links; four deliberate cross-campus directions; original captions,
descriptions, aliases, uncertain capture heights/north, credits and retired
groups; one preview-sheet identity; thirteen tab IDs; report-only precedence
over `?dev=1`; root `/foss-earth-sw.js` scope; unchanged legacy scene and older
resource bytes; and update checking followed only by explicit Reload.

These checks preserve and exercise current content/controls. They make no claim
that future accessibility, photo alignment, placement accuracy or media work is
complete. Unknown GPU identity is recorded as unknown; a requested/obtained
backend mismatch fails. Interception mode cannot qualify workers and is rejected.

# First local compiled Campus smoke

The public `@umn-vr/browser-testing/local-smoke` entry prepares a bounded first
human-preview check over the actual four-route compiled assembly. Its
`createCompiledCampusSmokeInput` and `assertCompiledCampusSmokePorts` gates are
data-only; supplying hash-shaped values is not artifact qualification. Actual
execution requires measured checked assembly/App/native-host/Scenes/media and
navigation receipts, a reviewed native observation driver source, the exact
accepted shared browser helper, one named loopback port and a fresh coordinator
grant. Source plans, old archive previews, supplied runtime observations and
synthetic drivers are rejected.

`runCompiledCampusSmoke(input, ports)` imports actual
`@foss-earth/browser-testing/page` only after the input/port gates, then uses
`openHeadlessPage` for browser startup, DOM evaluation, screenshots, evidence
and owned shutdown. The caller starts and stops the explicitly granted compiled
server. This module never acquires tools or media, serves fixtures, imports a
renderer or copies a generic browser harness. Public helper startup/command/
close/exit bounds remain mandatory; the first smoke wall is at most five minutes.

The check fetches and verifies exact compiled HTML, uses the existing Campus
selector assertion and follows the real visible selector links to Minneapolis,
Saint Paul and Twin Cities. Each route must display a nonzero native canvas and
serve its exact public producer document. Existing Campus assertions verify
48/12/60 authored membership/order, captions, placements, unknown heights/north,
asset identity, rights notices, preview-sheet cells and all original combined
links/group provenance. No generic scene or image validation is duplicated.

Built-in actions select the actual shared UI Scenes tab or menu, read the real
`.foss-earth-scene-entry` membership/order and click the actual
`button[data-panorama]`. They never install app state or simulate readiness.
The source-bound `ports.readSceneState(page, route, context)` must await and read
the actual compiled native scene/viewer state. The built-in
`readCompiledCampusSceneState` can supply this callback: it calls the Campus
host's read-only `window.__UMNVR_CAMPUS__.readSceneState()` and returns the exact
controller state, including `loading`, `errors` and `status`. The host reader
serializes the real public Scenes `controller.state()`; it sets no state and
does not fabricate loaded-policy facts. The bounded observation checks the
actual scene ID/revision, immersive phase, active panorama, rendering
availability, finite view and absence of errors. Missing callbacks, missing
host reader, synthetic state or intended targets fail. No lifecycle stub or
invented image-readiness field is installed here.

The check independently corroborates this entered native state with the real Scenes
`Entered` text, the native canvas and actual successful browser requests for
the selected photograph's measured resource URLs before its verification probe.
It then fetches bounded existing image bytes from the actual compiled origin
and checks their exact measured media-release digest/length. At most 16
declared resources of at most one MiB each are probed per route. This is startup
resource evidence, not a full corpus acquisition/encoding check. Actual
on-screen screenshots are retained before returning to the Scenes tab.

Mandatory writer callbacks retain each screenshot and return its actual
path/digest/length; retain closed resource/browser evidence and return the same
byte acknowledgement; and retain the complete owner receipt. The final receipt
records inputs, actual route/DOM/native/resource observations, elapsed time,
screenshots, browser facts and normal owned exit. The shared
`assertCompleteBrowserEvidence` rejects dropped evidence, console/network
failures, signals and forced/timeout cleanup. Writer and cleanup failures make
the smoke fail and remain in the attached error receipt. No forced cleanup is
converted into a successful preview.

This check claims only actual startup/content/navigation/selected-photo evidence
for the one recorded browser; it makes no renderer/GPU/backend qualification.
It does not qualify the six-browser/backend
matrix, worker update/older-resource behavior, thirteen keyboard/focus control
proofs, all installer/bootstrap receipts, remote admission/publication or future
accessibility/media work. Those gates remain separate. Four new negative gate
tests are source prepared and UNRUN. No import, test, browser, server, media,
installation, build, commit or publication was executed during preparation.
